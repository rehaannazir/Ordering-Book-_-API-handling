# Book Store API Automation using Python Requests

This is a beginner-friendly Python API automation project where I used the `requests` library to interact with a Book Store REST API.  
The project demonstrates how to perform basic API operations such as fetching books, searching books, registering an API client, placing orders, updating orders, viewing orders, and deleting orders.

The main purpose of this project is to understand how real-world APIs work using HTTP methods like `GET`, `POST`, `PATCH`, and `DELETE`.

---

## Project Overview

In this project, I worked with a Book Store API and performed the following operations:

- Checked API server status
- Fetched the list of available books
- Searched a specific book by ID
- Used query parameters to filter books
- Registered an API client
- Generated an access token
- Placed a book order using authorization
- Viewed all orders
- Updated customer name in an order
- Deleted/cancelled an order

This project helped me understand how APIs are used in automation, backend communication, and real-world software systems.

## HTTP Methods Practiced

| Method | Purpose |
|---|---|
| GET | Fetch data from the API |
| POST | Send new data to the API |
| PATCH | Partially update existing data |
| DELETE | Remove existing data |
